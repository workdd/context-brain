# Context Brain

**Claude Code 세션의 컨텍스트를 들여다보는 로컬 대시보드.** 지금 무엇이 컨텍스트를 차지하고 있는지, 답변이 무엇을 보고 나왔는지, 무엇이 자리만 차지하고 있는지를 보여 줍니다.

Claude Code를 오래 쓰면 컨텍스트에 CLAUDE.md 규칙, 시스템 프롬프트, 스킬 목록, 읽은 파일, 셸 출력, 웹 검색 결과가 쌓입니다. 터미널에서는 이게 보이지 않습니다. Context Brain은 Claude Code가 남기는 세션 로그를 실시간으로 읽어서 아래 세 질문에 답합니다.

| 질문 | 보는 곳 |
|---|---|
| 컨텍스트가 얼마나 찼고, 압축까지 얼마나 남았나 | 상단 게이지 |
| 무엇이 자리를 차지하고 있나, 무엇을 줄일 수 있나 | 면적 지도 + 낭비 후보 |
| 이 답변은 무엇을 보고 나왔나 | 턴 타임라인 (흐름 + 답변 문장별 근거) |

![전체 화면](docs/overview.png)

## 빠른 시작

```bash
git clone https://github.com/workdd/context-brain.git
cd context-brain
npm install
npm start            # http://localhost:7788
```

브라우저를 열어 두고 다른 터미널에서 Claude Code를 쓰면 됩니다. 기본값은 **가장 최근에 수정된 세션을 자동으로 따라가는** 모드입니다. 다른 세션은 위쪽 목록에서 고릅니다.

Claude Code 세션이 없어도 데모로 확인할 수 있습니다.

```bash
npm run demo              # 가짜 세션이 한 단계씩 진행됨
node scripts/demo.js --static   # 세 턴을 한 번에 기록하고 멈춤
```

- Node.js 18 이상이 필요합니다. 런타임 의존성은 없습니다 (jest는 테스트용)
- three.js는 브라우저에서 CDN(jsdelivr, `three@0.160.0`)으로 불러옵니다
- 포트는 `PORT=8000 npm start`처럼 바꿀 수 있습니다

## 화면 구성

### 1. 컨텍스트 예산 (위)

| 요소 | 내용 |
|---|---|
| 현재 컨텍스트 | 마지막 API 응답이 보고한 입력 토큰 수 (캐시 포함). **실측값** |
| 게이지 | 압축 기준 대비 현재 크기. 65%를 넘으면 노랑, 85%를 넘으면 빨강 |
| 압축 기준 | 최근 세션 40개에서 **실제로 자동 압축이 일어난 직전 크기** 중 최댓값. 압축이 한 번도 없었으면 표시하지 않음 |
| 그래프 | 컨텍스트 크기 변화. 빨간 점선이 압축 기준 |
| 면적 지도 | 지금 컨텍스트에 남아 있는 항목. 타일 크기는 글자 수로 낸 추정 토큰. 이번 턴에 쓰이지 않은 항목은 흐리게 표시 |
| 낭비 후보 | 800토큰 이상 들어왔는데 마지막으로 쓰인 뒤 2턴 넘게 다시 쓰이지 않은 항목. 지도에서는 붉은 점선 |

면적 지도 위에는 "추정 합계 / 실측 / 차이"가 함께 나옵니다. 차이는 도구 정의, 대화 틀, 한글 과소 추정처럼 로그로 셀 수 없는 부분입니다.

### 2. 턴 타임라인 (가운데)

사용자 입력 하나부터 답변이 끝날 때까지가 한 턴입니다. 최신 턴이 위에 오고, 지난 턴은 한 줄로 접힙니다.

| 요소 | 내용 |
|---|---|
| 작은 뇌 | 그 턴에 쓰인 영역만 색으로 칠한 옆모습 썸네일. 점 크기는 들어온 토큰 수 |
| 머리줄 | 입력 문장, 영역별 개수, 완료 여부와 걸린 시간, 들어온 양, 턴이 끝났을 때의 컨텍스트 크기 |
| 흐름 | 도구 호출 순서. 숫자는 결과로 들어온 토큰, **빨간 테두리는 실패한 호출** |
| 답변과 근거 | 답변을 문장으로 나누고, 문장에 파일 이름 · 스킬 이름 · MCP 서버 이름 등이 **그대로 나오면** 그 항목을 칩으로 붙임 |
| 늘 실려 있던 것 | 규칙(CLAUDE.md), 시스템 프롬프트, 도구 목록, 훅 주입처럼 매 턴 컨텍스트에 들어 있는 것 |
| 이 턴을 뇌에서 보기 | 오른쪽 뇌가 그 턴에 쓰인 항목과 경로만 켬 |

압축이 일어난 자리에는 빨간 점선 줄이 들어갑니다. 그 아래 턴들의 파일 · 셸 · 웹 결과는 컨텍스트에서 빠진 상태입니다.

### 3. 컨텍스트 뇌 (오른쪽)

컨텍스트 종류마다 뇌 영역을 하나씩 두고 항목을 뉴런으로 그린 3D 미니맵입니다. `크게`를 누르면 화면 전체로 커지고 영역 이름이 나옵니다 (Esc로 복귀).

| 영역 | 뇌 위치 | 무엇이 들어오나 |
|---|---|---|
| 응답 | 앞쪽 | Claude의 생각과 답변. 모든 신호의 출발점이자 도착점 |
| 규칙 (CLAUDE.md) | 앞쪽 위 | 실린 CLAUDE.md 파일마다 뉴런 하나 |
| 도구 목록 | 꼭대기 | 스킬 목록, 에이전트 목록, MCP 안내, 지연 로드한 도구 스키마 |
| 서브에이전트 · 웹 | 앞쪽 좌우 | Agent 호출(종류별), WebSearch · WebFetch(호스트별) |
| 스킬 · MCP | 뒤쪽 좌우 | Skill 호출과 스킬 본문, `mcp__서버__도구` 호출(서버별) |
| 대화 · 셸 | 옆 아래 | 사용자 입력과 압축 요약, Bash 명령 (명령 1회 = 뉴런 1개, 이름은 명령 설명) |
| 파일 | 뒤쪽 | Read, Edit, Write, Grep, Glob |
| 기억 (훅 주입) | 안쪽 | SessionStart 훅 등이 넣은 추가 컨텍스트 |
| 시스템 프롬프트 | 아래 뒤 | 시스템 프롬프트, 환경, 날짜, 모델 정보 |

- 응답에서 뉴런으로 가는 **영역 색** 빛은 도구 호출, 뉴런에서 응답으로 오는 **흰색** 빛은 결과가 들어오는 것입니다
- 보고 있는 턴(기본은 지금 턴)에 쓰인 뉴런과 경로는 켜진 채로 남습니다
- 압축되면 전체가 붉게 번쩍이고, 빠진 뉴런은 회색이 됩니다

### 4. 상세 패널

뉴런, 면적 지도 타일, 흐름 칩, 낭비 후보 중 아무거나 클릭하면 열립니다. 실행한 명령이나 수정 내용 전체, 결과 앞부분, 사용 이력, 쓰인 턴 번호가 나옵니다. 목록 위에 마우스를 올리면 뇌에서 해당 뉴런이 잠깐 밝아집니다.

## 동작 방식

```
~/.claude/projects/<프로젝트>/<세션>.jsonl   Claude Code가 쓰는 세션 로그
        │  0.4초마다 새 줄만 읽음 (lib/tail.js)
        ▼
파서 (lib/parse.js)
  · attachment(instructions, skill_listing …)  → 로드
  · assistant tool_use                          → 사용
  · user tool_result (tool_use_id로 짝 맞춤)     → 결과
  · assistant text                              → 답변 본문 + 언급
  · usage                                       → 컨텍스트 크기 (실측)
  · system turn_duration / compact_boundary     → 턴 종료 / 압축
        │  Server-Sent Events (server.js, 127.0.0.1:7788)
        ▼
브라우저
  · public/model.js  면적 지도 배치, 문장 분리, 근거 연결, 낭비 판정
  · public/app.js    예산 · 타임라인 · 상세 화면과 3D 뇌 (three.js)
```

- Claude Code 설정이나 훅을 건드리지 않습니다. 로그 파일을 읽기만 합니다
- 서버는 `127.0.0.1`에만 열립니다. `~/.claude/projects` 밖의 파일은 요청해도 404를 돌려줍니다
- 서브에이전트 내부 작업(사이드체인)과 claude-mem 관찰 세션은 그리지 않습니다

## 읽을 때 주의

- **근거 칩은 이름 일치 기준입니다.** 답변 문장에 파일 이름 등이 그대로 나온 경우만 연결합니다. 이름을 말하지 않고 내용만 쓴 문장은 근거가 없는 것처럼 보입니다. 모델 내부의 attention은 API로 알 수 없습니다.
- **항목 토큰은 추정치입니다.** 글자 수를 4로 나눈 값이고, 이미지는 장당 1,600으로 셉니다. 한글처럼 글자당 토큰이 많은 언어는 실제보다 작게 나옵니다. 위쪽 "현재 컨텍스트"만 API 실측값입니다.
- **압축 기준은 관측값입니다.** 모델이나 설정이 다른 세션의 압축 크기가 섞일 수 있습니다.
- **낭비 후보는 제안입니다.** 다시 쓰이지 않았다는 사실만 봅니다. 규칙처럼 조용히 참고되는 내용은 대상에서 뺐습니다.
- **로그 형식은 공개 규격이 아닙니다.** Claude Code 버전이 바뀌면 일부 항목이 안 잡힐 수 있습니다. 파서는 모르는 항목을 건너뜁니다.

## 개발

```bash
npm test             # jest, lib/ 와 public/model.js 커버리지 포함
```

| 파일 | 역할 |
|---|---|
| `lib/parse.js` | 로그 한 줄 → 이벤트 변환 (영역 분류, 토큰 추정, 상세 미리보기, 답변 본문) |
| `lib/tail.js` | 커지는 파일 따라 읽기 (덜 쓴 줄은 다음 읽기로 넘김) |
| `lib/sessions.js` | 세션 목록, 경로 검사, 관측된 압축 기준 |
| `server.js` | 정적 파일 + `/api/sessions` + `/api/limits` + `/api/stream` (SSE) |
| `public/model.js` | 화면과 무관한 판단 로직 (브라우저와 jest 공용) |
| `public/app.js` | 화면 전체와 3D 뇌 |
| `scripts/demo.js` | 임시 폴더에 가짜 세션을 만들어 뷰어를 띄움 |

`CLAUDE_PROJECTS_DIR` 환경 변수로 로그 폴더를 바꿀 수 있습니다.
