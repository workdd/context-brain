# Context Brain

Claude Code 세션 컨텍스트를 3D 뇌로 보여 주는 로컬 뷰어. 컨텍스트 종류마다 뇌 영역을 하나씩 두고, 그 영역이 쓰이는 순간 빛나게 한다.

```bash
npm install
npm start          # http://localhost:7788
npm test
```

설정 변경이나 훅 등록이 필요 없다. `~/.claude/projects/*/*.jsonl` 세션 로그를 0.4초마다 읽는다. 서버는 127.0.0.1 에만 열린다.

## 영역과 신호

| 영역 | 로그에서 오는 신호 |
|---|---|
| 규칙 (CLAUDE.md) | `instructions` 첨부: 실린 CLAUDE.md 파일마다 뉴런 하나 |
| 시스템 프롬프트 | `prompt_snapshot`, 환경, 날짜, 모델 첨부 |
| 기억 (훅 주입) | 훅이 넣은 추가 컨텍스트 (claude-mem 등) |
| 도구 목록 | 스킬 목록, 에이전트 목록, MCP 안내, 지연 로드 도구 스키마 |
| 대화 | 사용자 입력, 압축 요약 |
| 파일 | Read, Edit, Write, Grep, Glob |
| 셸 | Bash (실행 프로그램 이름별로 묶음) |
| 웹 | WebSearch, WebFetch (호스트별) |
| 서브에이전트 | Agent (에이전트 종류별) |
| 스킬 | Skill 호출, 스킬 본문 로드 |
| MCP | `mcp__서버__도구` (서버별) |
| 응답 | 생각, 답변 |

- **사용**: 응답 영역에서 대상 영역으로 신호가 나간다
- **결과**: 도구 결과가 대상 영역에서 응답 영역으로 돌아온다
- **언급**: 답변 본문에 앞서 다룬 파일 이름이나 스킬 이름이 그대로 나오면 그 뉴런이 다시 빛난다
- **압축**: 뇌 전체가 붉게 번쩍이고, 컨텍스트에서 빠진 뉴런은 회색이 된다

## 읽을 때 주의

- 뉴런 크기의 토큰은 글자 수/4 로 낸 추정치다. 이미지는 장당 1,600 으로 센다. 상단 "현재 컨텍스트"만 API 가 보고한 실제 값이다
- 빛은 실제로 일어난 사용 기록이다. 모델 내부 attention 이 아니다. 컨텍스트에 실려 있지만 조용히 따르기만 한 규칙은 빛나지 않는다
- 서브에이전트 내부 작업(사이드체인)은 그리지 않는다
